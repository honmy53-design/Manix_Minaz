نسخه و هستهٔ سرور

نسخه‌ها از فهرست رسمی سازندگان دریافت می‌شوند؛ فقط نسخه‌های پایدار Minecraft.

انتخاب نسخهٔ Minecraft

Paper

سیوت را بی‌احتیاط جابه‌جا نکن.

  • بازی باید خاموش باشد. قبل از تغییر، بکاپ کامل گرفته می‌شود.
  • دنیا پاک نمی‌شود؛ اما Downgrade در خود Minecraft ممکن است دنیا را خراب کند.
  • مودها و پلاگین‌های احتمالاً ناسازگار حذف نمی‌شوند؛ JARهایشان به disabled-addons منتقل می‌شود.
  • برای مود، Fabric / Forge / NeoForge انتخاب کن. برای پلاگین، Paper / Purpur.
  • تنظیم Java روی «خودکار» باشد تا از نسخهٔ مناسب استفاده شود. Vanilla مود اجرا نمی‌کند.
اول از بکاپ مهمت یک نسخه روی کامپیوتر ذخیره کن؛ بکاپ روی همان Volume جای نسخهٔ خارج از سرور را نمی‌گیرد.

JAR دستی / Spigot

JAR اجرایی سرورِ مورداعتماد خودت، نه نصاب یا پلاگین. مانیکس BuildTools را اجرا یا Spigot را از سایت غیررسمی دانلود نمی‌کند.

هسته‌های روی Volume

هستهٔ فعال پاک نمی‌شود. حذف یک هستهٔ قدیمی ممکن است بازیابی بکاپ وابسته را به نصب مجدد همان نسخه نیازمند کند.

بکاپ و سیو دنیا

دنیات، مودها، پلاگین‌ها و تنظیمات را نگه دار.

بکاپ کامل شامل فایل‌های بازی است؛ رمز پنل در آن نیست. هنگام بکاپِ بازیِ روشن، بازی موقتاً متوقف و سپس دوباره اجرا می‌شود. بازیابی فقط در حالت خاموش مجاز است.

بکاپ‌های ذخیره‌شده

نام بکاپ زمان ذخیره حجم عملیات

بکاپ خودکار

فاصلهٔ زمانی و تعداد بکاپ‌های خودکار را از تنظیمات انتخاب کن. بکاپ‌های دستی خودکار پاک نمی‌شوند.

یک نسخه خارج از Railway

پاک شدن Volume، بکاپ‌های داخلش را هم پاک می‌کند. فایل ZIP مهمت را روی کامپیوتر یا فضای دیگری نگه دار و برای حفاظت بیشتر از بکاپ خود Railway هم استفاده کن.

متناسب با دنیای تو

تنظیمات و دامنه

منابع، قوانین بازی، راه‌اندازی خودکار و آدرس اتصال.

منابع و رفتار پنل

پورت عمومی را Railway اختصاص می‌دهد؛ تغییر پورت داخلی نیاز به اصلاح Target Port در TCP Proxy دارد. JVM فقط از فهرست امن مانیکس پذیرفته می‌شود؛ دستور Shell آزاد نیست.

دامنهٔ اختصاصی

ثبت دامنه در این فرم فقط آدرس و راهنمای DNS را تنظیم می‌کند؛ رکوردها را خودت در DNS و Railway می‌سازی.

پورت عمومی Railway لزوماً 25565 نیست. Cloudflare برای دامنهٔ بازی باید روی DNS only باشد؛ نوشتن دامنه به‌تنهایی DNS را تنظیم نمی‌کند.

تنظیمات بازی

server.properties
بازی باید خاموش باشد. پورت داخلی و RCON توسط پنل کنترل می‌شود.

اول هسته نصب کن.

فقط نمایش argv واقعی Java؛ شل یا دستور سیستم‌عامل قابل‌ویرایش نیست. مسیرها مربوط به کانتینر خودت‌اند.

راهنمای سریع

پنل و سرور Minecraft در یک کانتینر، با دو ورودی شبکه.

01

Volume دائمی

در Railway یک Volume به همین سرویس وصل کن و Mount Path را دقیقاً /data بگذار. بدون آن، اجرای پروژه در Railway عمداً متوقف می‌شود تا سیو با دیپلوی بعدی از بین نرود.

Replicas = 1 · Serverless / App Sleeping = خاموش

02

آدرس پنل

از Settings → Networking یک دامنهٔ HTTP بساز؛ Target Port برابر 8080 است (یا مقدار PORT). دامنهٔ اختصاصی پنل را از Custom Domain همان بخش اضافه و رکوردهای خواسته‌شده را در DNS ثبت کن.

03

آدرس بازی

در Settings → Networking، TCP Proxy را برای پورت داخلی 25565 فعال کن. آدرس و پورت عمومی ایجادشده را در بخش دامنه‌های پنل وارد کن. بازیکن‌ها همین host:port را در Java Edition وارد می‌کنند.

04

نسخه، مود، بازی!

یک هسته در بخش نسخه‌ها نصب کن. برای مود، Fabric/Forge/NeoForge؛ برای پلاگین، Paper/Purpur. EULA را بخوان و بپذیر. بعد روشن کن و در کنسول منتظر پیام Done بمان.

این پنل مخصوص یک سرور Minecraft Java و یک مالک است؛ VPS کامل، SSH عمومی، فروشگاه هاست یا سیستم چندکاربرهٔ ایزوله نیست. Bedrock و Geyser به UDP عمومی نیاز دارند و در این استقرار پشتیبانی نمی‌شوند.

چند نکته که به کارت می‌آید

  • خاموش کردن در پنل فقط فرایند بازی را می‌بندد؛ خود پنل و سرویس Railway همچنان روشن و ممکن است هزینه‌دار باشند.
  • RAM بازی علاوه بر heap، حافظهٔ native هم مصرف می‌کند. برای مودپک‌ها معمولاً منابع بیشتری لازم است.
  • لودر خودِ مود نیست: برای Fabric بسیاری از مودها Fabric API می‌خواهند. نصب Modrinth وابستگی‌های ضروری قابل‌تشخیص را هم نصب می‌کند.
  • فایل‌های runtime زیر /data/engines هستند و فایل‌های بازی زیر /data/server. دیتابیس پنل و نشست‌ها در فایل‌منیجر بازی نمایش داده نمی‌شوند.
  • README فارسی داخل پروژه، نصب Railway، DNS، وارد کردن سیو و رفع خطاها را کامل توضیح می‌دهد.

دنیاهای مانیکس

سیو را وارد کن، دنیا را عوض کن و خروجی سالم بگیر.

ساخت، تغییر، وارد کردن و حذف دنیا نیاز به بازیِ خاموش دارد. انتخاب دنیا فقط level-name را عوض می‌کند؛ تبدیل ابعاد یا فرمت نسخه‌ها خودکار نیست. حذف دنیای فعال ممنوع است.

دنیای تازه

بعد از ساخت، فعالش کن و بازی را روشن کن؛ خود Minecraft دنیا را تولید می‌کند.

وارد کردن World ZIP

level.dat در ریشه یا یک پوشهٔ دنیای اصلی؛ ابعاد Paper هم در کنار پوشهٔ اصلی قابل‌واردکردن‌اند. فایل موجود را بی‌خبر بازنویسی نمی‌کند.

ریسورس‌پک

فایل ZIP را نگه دار و تنظیمات دانلود کلاینت را فعال کن.

ZIP باید pack.mcmeta در ریشه داشته باشد. نسخهٔ پک باید با Minecraft کلاینت سازگار باشد. لینک دانلود دارای شناسهٔ تصادفی و بدون نیاز به ورود است تا بازی بتواند آن را بگیرد؛ فایل خصوصی را اینجا قرار نده.

بازی باید خاموش باشد؛ تغییر از روشن‌کردن بعدی اعمال می‌شود. SHA-1 خودکار محاسبه و همراه ZIP در بکاپ بازی نگه‌داری می‌شود.

حساب و امنیت مانیکس

یک مالک؛ نشست‌های واقعی، ۲FA و API Key با دسترسی محدود.

پروفایل مالک

ایمیل فقط برای ثبت اطلاعات است؛ تأیید ایمیل، SMTP و بازیابی خودکار ایمیلی وجود ندارد. نام کاربری ورود از PANEL_USERNAME تنظیم می‌شود.

تغییر رمز عبور

همهٔ نشست‌ها و API Keyها لغو می‌شوند. رمز تغییرکرده بعد از Redeploy حفظ می‌شود؛ تغییر واقعی PANEL_PASSWORD در Railway راه بازیابی مدیریتی است.

ورود دومرحله‌ای TOTP

با کد شش‌رقمی برنامهٔ Authenticator یا کد بازیابی یک‌بارمصرف. ساعت گوشی باید دقیق باشد؛ Secret به‌صورت دستی قابل‌افزودن است.

دستگاه‌ها / نشست‌ها

API Key جدید

توکن فقط یک بار نمایش داده می‌شود. API Key راهی برای ساخت کاربر نیست؛ هر Scope مربوط به همین سرور است. دسترسی account، ۲FA، نصب هسته و Taskها با کلید مجاز نیست.
