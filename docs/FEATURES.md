# ماتریس ویژگی‌های مانیکس — نسخهٔ 1.1.0

این جدول **تک‌تک موارد فایل درخواستی** را پوشش می‌دهد. «موجود» یعنی قابلیت قبلی حفظ/استفاده شد؛ «افزوده» یعنی در این ارتقا اضافه/گسترش یافت؛ «محدود / دستی» یعنی دقیقاً فقط محدودهٔ شرح ستون آخر؛ «انجام نشده» یعنی دکمه/API نمایشی هم برای آن ساخته نشده است.

معماری: یک مالک، یک Minecraft Java و یک سرویس Railway، نه کسب‌وکار هاست چندمستاجری. موارد عمومی چندسرور/پلن/نود با قابلیت همان یک سرور اشتباه گرفته نشده‌اند.

**268 ردیف درخواست**: 128 موجود، 66 افزوده/گسترش‌یافته، 27 محدود/دستی و 47 انجام‌نشده. شمارش ردیف است، نه تعداد API مستقل؛ مثلاً Stop اجباری و Kill یک عملیات مشترک‌اند.

[README کامل](../README.md) · [API](API.md) · [گزارش تست](TESTING.md) · [امنیت](../SECURITY.md)

> آماده‌بودن کد، اثبات deploy واقعی روی Railway، موفقیت هر مود/نسخه یا gameplay نیست. موارد تست‌شده و تست‌نشده در گزارش آمده‌اند.

## چرا موارد سازمانی حذف شدند؟

- **ثبت‌نام، Subuser و فروش هاست:** به auth چندکاربره، RBAC کامل، جداسازی معتبر process/files/network، quota و چرخهٔ اشتراک نیاز دارند. Scope API Key جای این‌ها نیست.
- **Database:** ایجاد/حذف MySQL/MariaDB و credential نیاز به سرویس مستقل، provider و حفاظت/مهاجرت داده دارد؛ SQLite پنل ادعای این قابلیت را نمی‌کند.
- **پورت عمومی/چند Port و fleet:** کنترل actual allocation، ساخت/جابجایی نود و سرور، credential provider و طرح استقرار متفاوت لازم دارد؛ فرم DNS فقط راهنماست.
- **Billing/پلن/تمدید/Expire:** بدون پرداخت، حساب provider و منطق اشتراک واقعی، نشان‌دادن پلن و تاریخ ساختگی گمراه‌کننده است.
- **Shell آزاد و جداسازی:** پنل Shell عمومی ندارد؛ JVM args فقط allowlist و JAR مورداعتماد. Minecraft/مود و پنل UID مشترک دارند، پس برای مشتری ناشناس مناسب نیست.
- **SMTP/بازیابی ایمیلی:** ایمیل پروفایل فقط تماس است. Reset رمز از Environment و recovery TOTP واقعی‌اند، ولی ارسال ایمیل/verification اختراع نشده است.
